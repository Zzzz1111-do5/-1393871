# 军事大亨（Roblox）

踩按钮盖楼赚钱 → 造兵 → 布阵 → 开战。你本人也上战场：能开枪、开坦克开飞机、放支援技能。
之后升级科技、重生，还能和别的玩家约战、打排位。

## 直接玩

1. 用 Roblox Studio 打开 `MilitaryTycoon.rbxlx`。
2. 点「测试 → 开始游戏」。

左上角「当前目标」会告诉你下一步做什么，地上的绿色箭头指路。左边是小地图，上面是战场。

## 把 24 个兵种的 3D 模型导进去（做一次就行）

没导入也能玩，只是兵种用零件拼的方块模型。模型要上传到你自己的 Roblox 账号，所以这一步只能在你的 Studio 里做：

1. Studio 顶部「主页（Home）」→「导入 3D（Import 3D）」。
2. 选 `models/all_units.glb`。24 个兵种已经合成了这一个文件。
3. 设置不用改，点「导入（Import）」。模型会出现在场景里。
4. 保存：Ctrl + S，或「文件 → 保存到文件」。

开游戏时，脚本会自动把这些模型认出来，并收进 ServerStorage：
- 导入时 Studio 保不保留层级都没关系，按零件名前缀（`tank__…`）分回各个兵种。
- Output（输出）窗口会打印「用上了导入的原模型：aa、arty……」。
- 想一个一个导也行：`models/` 里有单个兵种的 `tank.glb`、`heli.glb`……

模型都来自 Sketchfab，CC-BY-4.0 授权。署名在 `models/credits.txt` 和游戏里的「致谢」。

## 发布到 Roblox

1. 先把模型导进去，见上面一节，导完记得保存。没导入也能发布，只是兵种是方块模型。
2. 「文件 → 发布到 Roblox」（Alt + P），选「创建新体验」：
   - 填名字、说明，类型选「战斗」或「大亨」。
   - 设备勾电脑、手机、平板。主机先别勾，游戏没做手柄操作。
3. 「主页 → 游戏设置」：
   - 「地点」：把这个地点的最多玩家数（服务器人数）设成 **6**。一个服务器只有 6 块基地，第 7 个人进来会被踢出去，提示「基地都有人了」。Studio 里找不到这一项的话，在网页 create.roblox.com → 你的体验 → 地点 → 配置里改。
   - 「安全」：打开「允许 Studio 访问 API 服务」，这样以后在 Studio 里测试也能存档。线上服务器不开这一项也能存档。
   - 「权限」：改成公开。第一次公开前，Roblox 会要求在 create.roblox.com 上填「内容成熟度问卷」（Maturity & Compliance）。
   - 「基本信息」：上传图标（512 × 512）和缩略图（1920 × 1080），可以在 Studio 里截游戏画面。
4. 测试：
   - 多人：Studio「测试」页选几个玩家加服务器一起开，试约战、突袭。
   - 排位赛跨服匹配、传送到对战服务器：只有发布后在真服务器里才能用。Studio 里只能服内匹配。
5. 以后更新：
   - 改完再「发布到 Roblox」，就覆盖线上版本。
   - 已经开着的服务器还是旧版本：到 create.roblox.com → 地点 → 「⋯」→ 重启服务器换成新版本。
6. 注意：
   - 模型用发布这个游戏的同一个账号（或群组）导入。
   - 模型是 CC-BY 授权，游戏里的「致谢」按钮写着署名，别删。体验说明里也可以贴一份 `models/credits.txt`。

## 图标和宣传图

`promo/` 里有现成的：
- `图标_512.png`：512 × 512，在「Experience Settings → 基本信息」或网页上体验的图标那里上传。
- `宣传图_1.png` ～ `宣传图_5.png`：1920 × 1080，在缩略图（Thumbnails）那里按顺序上传，第一张是封面。
- 英文版在 `promo/en/`（英文名 Army Base Tycoon）：`icon_512.png`、`thumb_1.png` ～ `thumb_5.png`。

画面是从游戏里真实的场景导出、用预览工具渲染的（`tools/test/promo_export.luau` 导出场景），和 Roblox 里的样子有点区别：Roblox 里有贴图、灯光和粒子。以后可以换成游戏里的真截图。

## 存档

- 在 Studio 里测试时默认不存档，屏幕上会提示「存档没读到」，正常现象。
- 要存档：先发布游戏，再到「游戏设置 → 安全」打开「允许 Studio 访问 API 服务」。
- 发布后，在线玩家的进度会自动存档。

## 出了问题

- 屏幕上方出现红条，就是脚本出错了。把红条截图发给开发者。
- 一出错的那一步会被跳过，游戏不会整个卡死。

  - 门口操场上一排人一起做俯卧撑，教官在旁边看着；旁边有单杠和轮胎。
- 西边工业区：从基地西墙南段的「工业区大门」出去。场地上有路、围栏、路灯和指示牌，十栋新建筑：
  - 油井 A / B / C：抽油机点头，曲柄和配重在转。
  - 炼油厂：火炬顶上烧着火。盖好后油井收入 ×1.5。
  - 弹药厂：传送带上一个个弹药箱送进卡车。
  - 钢铁厂：炉口发光、出铁沟里流着铁水，烟囱冒烟。
  - 矿场：矿车沿铁轨从坑道跑到矿仓，井架天轮在转。
  - 核电站：冷却塔冒白汽。盖好后工厂收入再 ×1.3。

  - 导弹发射井：盖好后打仗时多一个支援技能「巡航导弹」（电脑按 M）。放的时候井盖滑开、冒烟，导弹从工业区升空，划一道高弧线落到战场，炸出大火球和冲击波。拦截炮挡不住。
- 建筑升级：有收入的楼都能升到 Lv.5。
  - 每升一级收入多原来的一半，Lv.5 是 3 倍。
  - 居民楼、工厂、银行升级后会长高。
  - 楼顶牌子上有级数和星星。
  - 走到楼旁边按住 E 就能升；左边菜单的「建筑」面板里能一口气升。
  - 级数会存档，重生时清零。
- 新的每日任务：升级 3 次建筑。左上角的目标在钱够时会提示去升级。

## 0.6 版新内容

- 手机界面重做：
  - 原来手机上界面缩得太小，字只有 8 像素左右。现在放大到大约 0.83 倍，换了一套紧凑排版。
  - 兵工厂能收起，布阵时自动收起，回基地再打开。
  - 打仗时技能按钮在右边一竖列，右手拇指够得着；钱和关卡信息让给战场。
  - 按钮都让开了摇杆、跳跃键和底部的背包栏。
  - 手机上不放小地图，地上的箭头照样指路。
- 手机开直升机、飞机：按住「升高」「降低」调高度。运兵直升机降到最低就会放兵。原来只有空格 / C，手机上放不了兵。
- 电脑：
  - 关掉了 Roblox 自带的玩家列表。它在右上角，盖住了兵工厂的标题、页签和战报。同服务器的玩家在「真人对战」里能看到。
  - 兵工厂高度跟着屏幕走，不再压住下面那排按钮。
- 战区天气：镜头对着哪个战区的战场，就下那里的天气、换那里的天色，回基地慢慢放晴。
  - 沙漠：风沙，天色发黄。
  - 雪原：下雪，天色冷白。
  - 城市废墟：烟尘、碎屑，灰蒙蒙。
  - 火山：落灰、往上飘的火星，天色发红。
- 基地里有起降：
  - 机场跑道头停着一架战斗机，隔一会儿滑跑起飞飞向战场，过一阵从战场那边进场降落、滑回停机位。
  - 直升机场的直升机起飞绕一圈再落回来。
  - 起降只在各自的客户端里播，不占网络。导入了模型的话，用的就是导入的歼-20、阿帕奇。

## 改代码

- 脚本都在 `src/`，目录和 Rojo 的约定一样：
  - `src/ReplicatedStorage/Config.lua`：所有数值，包括兵种、建筑、技能、关卡。
  - `src/ServerScriptService/Main/`：服务器。
  - `src/StarterPlayer/StarterPlayerScripts/Client/`：客户端。
- 生成 rbxlx：要先装 [Lune](https://github.com/lune-org/lune)，然后在仓库根目录运行 `lune run tools/build.luau`。
- 也可以直接在 Studio 里改脚本；改完之后，这里的 `src/` 就不是最新的了。
- 重新合并模型包：`python3 tools/merge_glb.py models models/all_units.glb`。

## 不开 Roblox 也能测（`tools/test/`）

用 Lune 模拟一个 Roblox 服务器加客户端。实例和属性都按 Roblox 的 API 检查，远程事件、DataStore 也是模拟的。

在 `tools/test` 目录里运行：

```
lune run flow_old.luau ../../MilitaryTycoon.rbxlx
lune run flow_new.luau ../../MilitaryTycoon.rbxlx
lune run units.luau ../../MilitaryTycoon.rbxlx
lune run visual.luau ../../MilitaryTycoon.rbxlx
lune run import_sim.luau ../../MilitaryTycoon.rbxlx ../../models/all_units.glb
lune run import_sim.luau ../../MilitaryTycoon.rbxlx ../../models/all_units.glb flat
lune run theaters.luau ../../MilitaryTycoon.rbxlx
lune run mobile.luau ../../MilitaryTycoon.rbxlx
lune run perf.luau ../../MilitaryTycoon.rbxlx
lune run upgrade.luau ../../MilitaryTycoon.rbxlx
```

- `flow_old`：老功能走一遍（盖楼、造兵、开战、开枪、开车、突袭、约战、重生）。
- `flow_new`：新功能（技能、补给箱、评星、老兵存档、结算出错的保底）。
- `units`：新兵种的机制。
- `visual`：地图指引、建筑动画、机场起降、兵营里面（门洞走得进去、灯、床、俯卧撑）。
- `import_sim`：模拟导入模型包。
- `theaters`：战区（换战区、播报、速度射程倍数、火山弹、竞技场、天气）。
- `mobile`：手机（紧凑排版、收起兵工厂、技能栏竖排、直升机升降和放兵）。
- `perf`：一个玩家那里有多少零件（6 人满服、工业区都盖满、都在打仗时约 2 万个）。
- `upgrade`：建筑升级、工业区、雷达站和导弹发射井（巡航导弹、井盖开合、冷却）、存档读回级数、重生清零。
- 界面预览：
  1. `lune run ui_export.luau <rbxlx> 输出.js pc`（或 `phone`）：把几个场合的界面导出来。
  2. 用 `node ui_shot.cjs <输出目录> <截图目录>` 截图，要先装 Playwright；也可以直接用浏览器打开 `ui_view.html?data=输出.js&s=pc_base`。
  3. 截图的同时会列出这几类问题：面板压住、被 Roblox 自带界面挡住、字溢出、字太小。
- `export_scene.luau <rbxlx> <输出.json>`：把场景导出成 JSON（零件、地形填充），可以用来做预览图。

渲染、物理、Roblox 自带的镜头和角色控制模拟不了。上线前还是要在 Studio 里实际玩一遍。
