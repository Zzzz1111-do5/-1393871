# 军事大亨（Roblox）

两栖……不对，是陆空一体的军事大亨：踩按钮盖楼赚钱 → 造兵 → 布阵 → 开战（你本人也上战场，能开枪、开车、开飞机、放支援技能）→ 升级、重生、和别人约战 / 排位。

- `MilitaryTycoon.rbxlx`：直接用 Roblox Studio 打开就能玩（打开后点「测试 → 开始游戏」）。
- `models/`：24 个兵种的 3D 模型（GLB）和署名 `credits.txt`。
- `src/`：全部脚本（和 Rojo 的目录约定一样）；`tools/build.luau` 把它们拼成 `MilitaryTycoon.rbxlx`。
- `tools/test/`：不开 Roblox 也能跑的测试台（Lune 模拟服务器 + 客户端），`flow_old.luau` / `flow_new.luau` 跑完整流程。

详细说明见下面「怎么用」，会随版本更新。
