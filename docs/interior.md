# 载具内饰（对标 Steel Beasts / DCS，拿来拍电影）

用户 11-21：所有载具一比一还原内饰和里面所有功能性的东西（屏幕、按钮、观瞄设备），坦克看 Steel Beasts，飞机看 DCS。

代码：`Client/Interior.lua`（运行：镜头、按键、动画、灯、屏幕数据）、`Client/InteriorDefs.lua`（各型的布局，真实尺寸，米；坦克、飞机）、
`Client/InteriorAFV.lua`（步战车、装甲车、突击炮、自行火炮、自行高炮、轮式车、卡车：按各型车体尺寸摆）、
`Client/InteriorKit.lua`（零件库、屏幕、乘员小人和反向运动学）、`Client/InteriorScreens.lua`（屏幕页面、按键的真实功能）。
测试：`python3 tools/mock/run.py tools/mock/interior.lua veh=m1a2|ztz99a [dump=<目录>]`（坦克）、
`python3 tools/mock/run.py tools/mock/interior_all.lua veh=<型号>`（其他地面载具，21 型）、
`python3 tools/mock/run.py tools/mock/cockpit.lua air=j20|j35|j50|j16|j15t|f35|f22|a10c|z10|ah64e|uh60|z20|ch47|h6k|b2 [dump=<目录>]`（飞机）；预览图：
`NODE_PATH=$(npm root -g) node tools/mock/interior_view.cjs <目录>/interior_m1a2.json <输出前缀>`（three.js 用 tools/trailer 的，`cd tools/trailer && npm ci`）。

## 按键（开坦克时）

| 键 | 作用 |
|---|---|
| C | 进出车内（车外 → 上次坐的乘员位 → 依次换位 → 车外） |
| F2 / F3 / F4 / F5 | 驾驶员 / 炮长 / 车长 / 装填手 |
| Shift | 本位的主镜：炮长主瞄准镜；车长热像仪 / 周视镜；驾驶员视觉增强器 / 夜视仪；装填手潜望镜 |
| G | 备用镜：炮长辅助瞄准镜；车长看炮长的主瞄准镜画面；驾驶员后视热像 |
| T（车外） | 直接坐到车长位、开车长的主观瞄：99A 是车顶那个多边形观瞄舱里的周视瞄准镜，M1A2 是 CITV（鼠标转镜头、炮塔不动；Z 变倍、V 换热像）；这样开的镜里再按 T 回车外 |
| T | 第三个观瞄设备（11-22 起坦克不带机枪：M1A2 车长的 CROWS 这一位空着，按 T 没反应；车里那块 CROWS 屏只剩车顶摄像头） |
| 鼠标中间的小点对准屏幕边的按键、左键 | 按这个键（下面说明） |
| B | 导演镜头（跟着车走的自由镜头：方向键、PageUp/PageDown、Ctrl 慢、滚轮变焦） |
| L | 车内灯：白 → 蓝绿 → 红 → 关 |
| U | 藏起全部界面（拍片） |
| 滚轮 | 乘员位上变焦；观瞄设备里换视场 |

开镜：镜头先凑到目镜上，切进去以后先黑、亮的圆从边上滑进来变大（眼睛找出瞳），猛转时一边露出黑月牙。

## M1A2 SEPv2（用户 11-23：「我这个 M1A2 是 SEPv2」）

- 驾驶员（车体前部中间，半躺）：三具潜望镜、DVE 显示器、驾驶员综合显示器 DID、T 形把（跟着方向转）、两个哈龙灭火瓶
  - DID 上排：MAIN MENU（主页：车速、转速、挡位、油量、炮塔方位、告警）、STATUS（发动机 / 传动 / 液压 / 电气读数）、W/C/A（告警 / 注意 / 提示）、
    NAV（指向下一个目标点）、MAINT（机内自检）；下排：PUSH TO START（起动）、SHUT OFF（熄火——熄了车开不动）、TAC IDLE（战术怠速）、
    LAMP TEST（所有指示灯亮一遍）、ALARM ACK（确认告警）
- 炮长（炮塔右前）：主瞄准镜 GPS（目镜、护额垫）、"凯迪拉克" 双握把（跟着炮塔转、炮俯仰的速度摆）、辅助瞄准镜 GAS、手动方向 / 高低机、炮长控制显示面板 GCDP
  - GCDP 上排：MAIN（主菜单）、AMMO（弹种：SABOT / HEAT / MPAT / AMP / CAN）、RANGE（手动装定距离）、ADJUST（校炮 / 归零）、LRF（激光首 / 末回波）；
    下排：WHT/BLK（热像极性，真的切瞄准镜的白热 / 黑热）、3X/10X（真的切倍率）、FCS（正常 / 应急 / 手动）、BSGT（校炮）、MRS（炮口基准更新）
- 车长（右后，坐得高）：六具观察镜的指挥塔、独立热像仪显示器 CITV、指挥综合显示器（JBC-P 战术地图）、CROWS 屏幕和握把、车长操纵握把、主瞄准镜延伸目镜
  - CITV 上排：WHT / BLK、WFOV / NFOV（宽 3 倍 / 窄 13 倍）、SYM（符号开关）；下排：MAN（手动扫描：跟着车长的视线）、AUTO（扇区自动扫描）、
    GUN LOS（随炮）、GPS LOS（看炮长主瞄准镜画面）、DESIG（指示 / 猎-歼：炮塔自动转到热像仪看的方向）
  - 战术地图上排：MAP / MSG（敌情、据点通报）/ STAT（本车弹药、油、损伤）/ NAV / POS；下排：ZOOM+ / ZOOM- / OVLY（标绘开关）/ BRT+ / BRT-
- 装填手（左）：折叠座椅、装填手潜望镜（能转）、电台、装填手面板（待发灯）、膝动开门开关
- 尾舱两扇装甲滑门后各 18 发待发弹（弹底朝乘员舱），弹架上的弹按剩下的弹数少下去
- 开炮：炮闩后坐 0.305 米（M256 真实行程）、复进时立楔式炮闩自动打开；装填手转身、膝盖顶开舱门、抽弹、转回来翻过弹头推进炮膛、关闩、拨待发，按这门炮的装填时间走完

## ZTZ-99A

- 三人车组：驾驶员（方向盘、数字仪表、三具潜望镜、微光夜视）、炮长在左（主瞄准镜、备用瞄准镜、火控计算机面板、炮长显示器）、车长在右（周视瞄准镜、综合显示终端）

  药筒底盘从炮塔顶后部的抛壳窗抛出去；转盘里的弹打一发少一个，补给车补了弹才补满

  极性 / 倍率 / 火控方式 / 自检 / 复位）、驾驶员仪表（主菜单 / 状态 / 故障 / 导航 / 维护、起动 / 熄火 / 怠速 / 灯检 / 消音）、车长周视镜（白热 / 黑热 / 宽 / 窄视场、手动 / 扫描 / 随炮 / 指示）

## 资料和推测

- 按键的标签和功能出自公开的美军训练资料、Steel Beasts 社区说明、陆军研究报告（CITV 的手动 / 自动扫描、随炮、指示，DID 的起动 / 熄火 / 主菜单 / 维护 / 诊断，GCDP 的主菜单 / 调整 / 归零 / 校炮 / 炮口基准）
- 美军手册原文（TM 9-2350-388 系列）和几个学习卡片站有机器人验证，没法直接读；屏幕的具体排版、99A 的车内布局（照 T-72 / 96 系一脉相承的做法和公开镜头）有推测
- 内饰原来全是程序拼的零件；11-22 起一部分换成 Sketchfab 上的 CC-BY 原模型（下一节），没生成好 / 生成不了时照旧用零件拼；M1A1 暂时用 M1A2 的内饰，96 式用 99A 的
