用户 11-21：所有载具一比一还原内饰和里面所有功能性的东西（屏幕、按钮、观瞄设备），坦克看 Steel Beasts，飞机看 DCS。

代码：`Client/Interior.lua`（运行：镜头、按键、动画、灯、屏幕数据）、`Client/InteriorDefs.lua`（各型的布局，真实尺寸，米；坦克、飞机）、

测试：`python3 tools/mock/run.py tools/mock/interior.lua veh=m1a2|ztz99a [dump=<目录>]`（坦克）、
`python3 tools/mock/run.py tools/mock/interior_all.lua veh=<型号>`（其他地面载具，21 型）、
`python3 tools/mock/run.py tools/mock/cockpit.lua air=j20|j35|j50|j16|j15t|f35|f22|a10c|z10|ah64e|uh60|z20|ch47|h6k|b2 [dump=<目录>]`（飞机）；预览图：

## 按键（开坦克时）

| 键 | 作用 |
|---|---|
| C | 进出车内（坦克：车外 → 炮长位 → 车外；别的车：车外 → 上次坐的乘员位 → 依次换位 → 车外） |
| F2 / F3 / F4 / F5 | 坦克锁在炮长位（用户 11-23：「不要更新坦克驾驶员视角 就只锁定开炮手就完事了」），按了还是炮长位；步战车等别的车照旧换乘员位 |
| Shift | 本位的主镜：炮长主瞄准镜；车长热像仪 / 周视镜；驾驶员视觉增强器 / 夜视仪；装填手潜望镜 |
| G | 备用镜：炮长辅助瞄准镜；车长看炮长的主瞄准镜画面；驾驶员后视热像 |
| T（车外） | 直接开车长的主观瞄（人在炮长位）：99A 是车顶那个多边形观瞄舱里的周视瞄准镜，M1A2 是 CITV（鼠标转镜头、炮塔不动；Z 变倍、V 换热像）；这样开的镜里再按 T 回车外 |
| T | 第三个观瞄设备：坦克炮长位上是车长的主观瞄（周视镜 / CITV，11-23 锁在炮长位以后挪过来的）；11-22 起坦克不带机枪，CROWS 那一位没有了 |
| 鼠标中间的小点对准屏幕边的按键、左键 | 按这个键（下面说明） |
| B | 导演镜头（跟着车走的自由镜头：方向键、PageUp/PageDown、Ctrl 慢、滚轮变焦） |
| L | 车内灯：白 → 蓝绿 → 红 → 关 |
| U | 藏起全部界面（拍片） |
| 滚轮 | 乘员位上变焦；观瞄设备里换视场 |

开镜：镜头先凑到目镜上，切进去以后先黑、亮的圆从边上滑进来变大（眼睛找出瞳），猛转时一边露出黑月牙。
