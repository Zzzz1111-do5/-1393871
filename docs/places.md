# 一张图一个服务器（训练场、钢城、雪山各开各的）

用户 11-28：「能不能这样 训练场 还有各种地图单独做成一个服务器」。代码在 `src/ServerScriptService/Main/Places.lua`（认身份、传送）和 `SnowRange.lua`（训练场在雪山图上的靶道、靶车）。

## 怎么认是哪一种服务器

同一个游戏（体验）里建几个**地点（place）**，每个地点发布**同一份**地点文件 `RobloxTotalBattlefield.rbxlx`。服务器开起来时按**地点的名字**认自己是哪一种：

| 地点名字里有 | 这个服务器 |
|---|---|
| `训练场` / `range` / `试驾` | 训练场：开雪山图，只试驾（每人一条靶道、靶车、靶机），不打对战、没有人机 |
| `雪山` / `snow` | 只打雪山（不投票） |
| `钢城` / `city` | 只打钢城（不投票） |
| `沙海` / `sands` | 只打沙海（不投票） |
| 别的（起始地点） | 照旧：投票选图；有自己地点的那几张图不投，点了直接传送过去 |

名字里同时有「训练场」和「雪山」的（比如「雪山训练场」）算训练场。

## 在 Studio 里设置（只做一次）

1. 打开游戏，「文件 → 发布到 Roblox」先把起始地点发布好。
2. 「资源管理器（Asset Manager）→ 地点（Places）」右键「添加新地点」，起名「训练场」；需要的话再加「雪山」「钢城」。
3. 双击打开新地点，「文件 → 打开」本地的 `RobloxTotalBattlefield.rbxlx` 的内容（或者直接在资源管理器里对新地点「从文件更新」），再「文件 → 发布到 Roblox」到这个地点。每个地点都发布同一份文件。
4. 以后更新：每个地点都重新发布一次（或者用更新包 `ScriptsUpdate.rbxmx` 换脚本以后再发布）。

存档（DataStore）在同一个游戏的所有地点里共用：解锁的车、金币、设置到哪个服务器都一样。传送前服务器先把存档写进去（`G.saveNow`）。

## 玩起来是什么样

- 在战场服务器（起始、钢城、雪山……）点「试驾」：传送到训练场服务器，到了自动坐进那一辆。
- 在训练场里：下车回机库以后能接着试别的车（不用再传送）；点「开战」传送到想打的那张图的服务器（没选过图就回起始服务器），到了自动排上匹配。
- 选图界面里有自己服务器的图，按钮写「前往 X」，点了传送过去。
- 传送没成功（网络、地点没发布）：留在当前服务器，试驾就在这个服务器的训练场区块里试（`G.ensureRange` 现建）。
- 训练场服务器满了，Roblox 自动再开一个。

## Studio 里测试

Roblox 不让 Studio 里传送，所以 Studio 里照旧**一个服务器全包**：投票选图，训练场是这个服务器里单独的一块区块（`Zones.RANGE`），开服就建，主界面马上能试驾。

想在 Studio 里看某一种服务器：选中 Workspace，加一个字符串属性 `PlaceRole`，值写 `range`（训练场：雪山图上试驾）、`snow`、`city` 或 `sands`，再点「开始」。
