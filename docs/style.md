# 外观规范（全游戏统一）

用户 11-25：「现在整个游戏风格极其割裂……四不像」。定下来：玩法照写实载具对战这一类游戏做（科技树、乘员 / 模块伤害、X 光、真实弹道……C、D 在做），
**外观统一成我们自己的一套写实军事风格，不照搬任何一款别的游戏的样子**（界面美术、菜单、机库外观、名称都不一比一复刻）。
颜色、字体、字号、面板的值都在 `src/ReplicatedStorage/Theme.lua`，**所有界面从那里取，新界面也一样**——不要在模块里再自己定一套白、灰、绿、红。

## 原则

1. **黑白灰打底，颜色只表示意思。** 面板是深色半透明底 + 一圈细白线，字是白 / 灰。只有要说明「好 / 坏 / 注意」时才上颜色。
2. **颜色的意思全游戏一样：**
   - 绿 `GOOD` / `FRIEND`：自己人、完好、已拥有、能打穿、可以
   - 红 `BAD` / `FOE`：敌人、危险、坏了、打不穿、不行
   - 琥珀 `WARN`：注意、受伤、进行中（研究进度、装填）、金币
   - 灰白 `NEUTRAL`：中立据点
   - 亮绿 `HUD`：车上、飞机上的瞄准和飞行符号（准星、平显、雷达屏）——只此一种绿
   - **不用蓝色**（用户 11-21：蓝色全部改成绿色）
   - 例外：科技树**等级底色**（用户 11-25「载具科技树不同等级的载具背景颜色要有区别」）——`Theme.RANK` 一级一个压暗的军用色（灰绿、橄榄、沙褐、铜褐、砖红、紫褐、暗金），
     只用在等级横条、车卡车图底板、阵容卡、详情大图（`Theme.rankGrad`），不拿来表示好坏
3. **敌我按看的人算：** 自己这一边一律绿、对面一律红（`Theme.side(side)`），不按攻方 / 守方的固定颜色——计分板、击杀栏、小地图、名牌都一样。
4. **一屏只有一个主按钮**（白底黑字：出击、开始游戏、确定）；其余按钮灰底白字带细边；页签选中白底黑字。
   **一屏白底最多两块：页签 + 主按钮。** 次级的选中（预设、内油、分段键……）不填白：`Theme.setPicked`——RAISE 底 + 1 像素白描边 + 贴底 2 像素白线，
   没选中的透明底、细线、灰字（悬停字变白）；琥珀只留给「正在改的那个」和预览。
5. **方正、硬朗，但要有层次：** 圆角 2～3 像素，不用大圆角。用户 11-25「科技树没有设计感……整体 ui 也是」：允许面板、卡片车图底板用**竖向淡渐变**（`Theme.grad`）；
   不用花哨的阴影、彩色渐变。
   **卡片（格子）和战斗里的弹药栏一套画法**（WtTank.lua，用户 11-27 晚定的；整备 WsKit.lua 的 `K.card` 照它）：平涂深色半透明底（PANEL 0.35）+ 1 像素细线，
   不要玻璃渐变、**不抬起、不加状态色条**；悬停只把细线调亮（0.82 → 0.45）；**选中 = 1 像素琥珀描边 + 贴底 2 像素琥珀线**；
   「装着的 / 膛里那发」= 左边 2 像素白竖条；左上 14 × 14 键位框（等宽 12 灰，1 像素灰线），右上数目（等宽 15）；图后面垫一块横向柔光（白、透明 0.92、横着 1 → 0 → 1），
   不套框。空的、锁住的：底更淡、字和图变淡（FAINT / 35% 不透明），不另画颜色条。
6. **字：** 用户 11-25「字体不清晰」换成 Builder Sans；11-27「我觉得字体可以细一点」整体细一档——正文 BuilderSans、强调 BuilderSansMedium、
   大标题 BuilderSansBold（不再用 ExtraBold；Gotham 一律换掉）、数字和仪表 RobotoMono、卡片短标签 RobotoCondensed（`Theme.F.cond`）。
   字号只用 12 / 13 / 15 / 17 / 21 / 29 / 42（`Theme.S`）；中文不再自动加粗一档。战场上的字一律加黑描边（透明度 0.45）。
   Roboto 系（等宽、窄体）没有中文字形，中文退到引擎的后备字体——整备的 `K.text` 照 `Theme.F` 设字体、不再整行换粗体，新界面照这个做。
7. **说话的口气：** 短、名词为主、不用感叹号、不用表情符号；按键写成「K 呼叫炮击」这样。

## 动效

用户 11-27：「整个给载具配置武器的系统 做的很粗糙 我需要非常艺术经验的效果」。动效是质感的一部分，但要**短、克制、有用**：
它说明「东西从哪来、到哪去、哪个变了」，不拿来炫。时长、缓动都从 `Theme.T` / `Theme.EASE` 取，补间用 `Theme.tween(零件, { 属性 = 终值 }, 时长, 缓动, 延迟)`
（TweenService 包在 pcall 里，零件删了、属性写错都只是直接跳到终值）；自己逐帧插值的（镜头、3D 里的东西）用 `Theme.ease(缓动, 0～1)`。

| 场合 | 时长（`Theme.T`） | 缓动（`Theme.EASE`） |
|---|---|---|
| 悬停、描边变亮 | 0.12 秒（`hover`） | Quad 先快后慢（`hover`） |
| 选中：琥珀细描边 + 底边 2 像素（不抬起，同弹药栏） | 0.12 秒（`hover`） | Quart 先快后慢（`out`） |
| 数字滚动、条长变化（只在点了装上、改内油时滚；悬停预览直接换，扫一列卡时数字不一直转） | 0.22 秒（`num`） | Quart 先快后慢（`out`） |
| 界面里一小块展开、收起、换内容 | 0.22 秒（`ui`） | Quart 先快后慢（`out`） |
| 进场：面板从旁边滑进 24 像素 + 淡入（CanvasGroup） | 0.28 秒（`panel`） | Quart 先快后慢（`out`） |
| 退场 | 0.18 秒（`out`） | Quart 先快后慢（`out`） |
| 镜头换位（进整备、点挂点、换页签：`HangarStage.focus`） | 0.55 秒（`cam`） | Quart 两头慢（`cam`） |
| 装上一枚弹：从挂架下滑上去、琥珀轮廓淡掉 | 0.22 秒（`mount`） | Back 带一点回弹（`back`） |
| 一项研究完：描边琥珀变绿 | 0.6 秒（`done`） | Quart 先快后慢（`out`） |
| 弹药架一格一格填满 / 清空 | 每格 0.015 秒（`cell`） | — |

- **先快后慢**：界面上的东西一律 Out（马上有反应、慢慢停稳）；镜头两头慢（InOut）。**不用先慢后快（In）**——点了以后要等一下才动，显得迟钝。
- **进场、退场**：进场从它「来的方向」滑进一小段（24 像素）同时淡入，不从屏幕外飞进来；退场比进场短，只淡出、不滑远。
- **错开**：一列东西一起出来时每项晚 25 毫秒（`Theme.stagger(i)`），最多算到第 8 项，后面的和第 8 项一起出来——长列表不拖。
- **不用**：弹跳的大按钮、闪烁、循环呼吸的光、旋转的加载圈；颜色变化同样只表意（变好绿、变差红、预览 / 进行中琥珀）。
- 每一处动效都要能被打断：动画中途再点（换挂点、拖镜头）直接从当前状态接着走，不等它播完。
- **镜头动着的时候，跟着 3D 的标签先淡掉**（0.12 秒），停稳了再淡回来：一排编号不在眼前换位置。镜头不自己转（转到正侧面构图就坏了）。
- CanvasGroup 只在进场 / 退场那一小段用（整体淡入、滑动），动完把内容放回普通 Frame：CanvasGroup 在部分设备上把里面画成一张贴图，字会发糊。

## 屏幕上的位置（战场里）

| 位置 | 放什么 |
|---|---|
| 左上 | 飞机：飞行参数表；坦克：车组 / 模块状态 |
| 上中 | 比分条、据点、航向带 |
| 右上 | 圆形小地图（飞机时雷达屏在它下面、屏幕右侧中间） |
| 左中 | 飞机：雷达告警圆盘；「被发现」标记在它右边 |
| 左下 | 击杀栏 |
| 中下 | 武器 / 弹种、装填 |
| 右下 | 速度、档位（坦克） |
| 正中 | 只放准星、命中提示（一闪就走） |
